# AngleIyagi

**An angle meter for your Android phone — measure the tilt of a solar panel, a roof or a wall, and save a photo with the angle on it.**

[English](README.md) · [한국어](README_ko.md)

## Why AngleIyagi?

- **Lay it down or stand it up.** Flat mode measures a surface like a solar panel or roof slope; side mode measures a wall or an edge.
- **Accurate even with a bumpy phone case.** Two-step measurement: measure, flip the phone, measure again — the error cancels out.
- **Your own zero.** Set the current angle as zero and measure relative to it.
- **Proof on the spot.** Turn on the camera, see the angle over the live picture, and save the photo to your gallery.
- **More than an angle.** Side-to-side lean, a compass, and altitude from both the barometer and GPS.

## Features

- Flat and side measurement modes, large easy-to-read display
- Two-step (flip) approximation to cancel case and sensor error
- Set current value as zero; reset to raw value
- Camera view with angle overlay; save to the "AngleIyagi" album
- Lean angle, compass, barometric and GPS altitude
- Multiple UI languages
