# AngleIyagi

**안드로이드 휴대폰 각도계 — 태양광 패널·지붕·벽의 기울기를 재고, 각도가 찍힌 사진으로 남깁니다.**

[English](README.md) · [한국어](README_ko.md)

## 왜 AngleIyagi 인가

- **눕혀서도, 세워서도.** 평면 측정은 태양광 패널·지붕 경사 같은 면을, 측면 측정은 벽이나 모서리를 잽니다.
- **울퉁불퉁한 폰 케이스여도 정확하게.** 두 번 측정 — 재고, 폰을 뒤집어 다시 재면 오차가 상쇄됩니다.
- **내가 정한 0점.** 지금 각도를 0으로 잡고 그 기준으로 잽니다.
- **현장에서 바로 증거.** 카메라를 켜면 화면 위에 각도가 보이고, 그대로 사진으로 갤러리에 저장합니다.
- **각도 그 이상.** 좌우 기울기, 나침반, 기압계·GPS 고도까지.

## 기능

- 평면·측면 측정 모드, 크게 잘 보이는 표시
- 뒤집어 두 번 재는 근사 측정으로 케이스·센서 오차 상쇄
- 현재 값을 0점으로, 실측값으로 되돌리기
- 각도를 겹친 카메라 화면, "AngleIyagi" 앨범에 저장
- 좌우 기울기, 나침반, 기압 고도·GPS 고도
- 여러 나라 말 지원
